# Світ Ангеліни

Кубикова гра для Ангеліни: великий світ з біомами (луки, ліс, пустеля, сніжні гори, озера, цукеркова країна), тваринки, з якими можна подружитися, і 20 сердечок. Коли всі зібрано, посередині світу відкривається портал до замку принцеси Ангеліни, куди можна піти разом з друзями-тваринками.

Грати: відкрий `index.html` у браузері або сайт на GitHub Pages.

Керування на комп'ютері: W A S D (ходити), пробіл (стрибати), мишка (камера), клік (ламати або будувати), 1–0 (блоки).
На телефоні: джойстик, кнопка «Стриб», дотик до блока або тваринки.
